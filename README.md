# watch-together-server

**Watch Together**
Комната для совместного просмотра фильмов и видео контента

**Идея проекта**
Сервис для совместного просмотра видео-контента с возможностью синхронизации и управления
просмотром несколькими пользователями в реальном времени.

**Предполагаемые возможности**
1. Создание комнат пользователями
2. Присоединение к другим комнатам по ссылке
3. Простой чат для участников комнаты
4. Синхронизированное воспроизведение/пауза/перемотка видео у всех
   пользователей комнты.
   В простой версии может быть управление только
   хостом, в более сложной можно добавить права и возможность
   дать управление сразу нескольким людям.

**Предполагаемый стек технологий**
1. Python (основной язык)
2. FastAPI(основной framework)
3. Uvicorn (сервер)
4. PostgreSQL (БД)
5. SQLAlchemy2 (работа с БД)
6. WebSocket (постоянное двустороннее соединение для синхронизации)
7. Pytest (тесты)
